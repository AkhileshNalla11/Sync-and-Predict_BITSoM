## What it does
Fuses a static EHR profile with 6 hours of wearable data (CGM, sleep, steps, heart rate) to predict two
events over the next 2 hours:
1. **Hyperglycaemia**: any CGM reading > 180 mg/dL
2. **Hypoglycaemia**: any CGM reading < 70 mg/dL (also reported for the nocturnal subset, 22:00-06:00)

A Streamlit clinician dashboard shows each virtual patient, both risks, their drivers and what-if scenarios.

## Data sources and synthetic-linkage disclosure
All data is generated by `src/data/synthetic_gen.py`. EHR traits are wired into the glucose dynamics
**by design**, so the EHR-sensor linkage is synthetic. See [data/README.md](data/README.md) and
[docs/synthetic_data_report.md](docs/synthetic_data_report.md).

## How to run

Python 3.10+. The full pipeline takes about 25 min on a laptop CPU (most of it is training the GRU models).
The dashboard opens at http://localhost:8501.

**Windows (PowerShell or Command Prompt)**
```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
scripts\run_pipeline.cmd        # generate data, train and evaluate everything
scripts\demo.cmd                # launch the dashboard
.venv\Scripts\python -m pytest  # tests
```
On Windows on ARM, create the environment with an x64 Python (LightGBM, SHAP and PyTorch have no native
ARM64 wheels), e.g. `uv venv --python cpython-3.12-windows-x86_64-none .venv`.

**Linux / macOS (or Git Bash on Windows)**
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
bash scripts/run_pipeline.sh
bash scripts/demo.sh
.venv/bin/python -m pytest
```
